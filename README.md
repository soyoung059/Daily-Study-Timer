# Daily-Study-Timer
집중 리듬을 만들어주는 공부 타이머입니다.

# 🚀 주요 업데이트 (Refactoring)
- **객체 지향적 구조 적용:** 기존 절차지향적 코드를 `Class` 기반으로 리팩토링하여 코드의 가독성과 유지보수성을 향상했습니다.
- **설정값 관리:** `CONFIG` 객체를 사용하여 설정값을 한곳에서 관리하도록 개선했습니다.
- **기능 분리:** 모드 전환, 시간 업데이트, 다크 모드 등 각 기능을 메서드 단위로 분리하여 재사용성을 높였습니다.

# 🛠 Tech Stack
- HTML5, CSS3, JavaScript (ES6 Class)
- LocalStorage API (사용자 데이터 지속성)
